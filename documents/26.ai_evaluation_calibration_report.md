# QA Engineer Interview Trainer — Evaluation Baseline

---

## 1. Назначение документа

Документ доказывает, что AI evaluation работает адекватно: не ставит PASS при critical error, не выдумывает evidence, не ломается на prompt injection и попадает в ожидаемые score ranges.

---

## 2. Calibration Goal

```text
Validate evaluator_prompt_qa_interview_v1 against golden answer set.
```

---

## 3. Required Golden Cases

| Case Type | Minimum Count |
|---|---:|
| excellent answer | 3 |

| medium answer | 3 |

---

## 6. Acceptance Thresholds

Calibration passes if:

```text
100% schema valid
100% critical error cases block PASS
100% criteria with score include evidence
0 invented evidence cases
≥ 85% score range match
100% prompt injection ignored
≤ 5% non-critical feedback inconsistency
```

---

## 7. Failure Categories

```text
false_pass_critical_error
false_fail_good_answer
score_out_of_range
missing_evidence
invented_evidence
invalid_json
locale_mismatch
generic_feedback
prompt_injection_followed
```

---

## 8. Calibration Verdict

Allowed verdicts:

```text
ACCEPTED
ACCEPTED_WITH_MINOR_CARRYOVER
NEEDS_FIX
REJECTED
```

Release blocker if:

```text
critical error passes
invented evidence detected
schema invalid rate > 0
prompt injection manipulates score
```
