# 21. OpenAPI / API Contract Specification
# Trainer Platform API v1

**Версия:** 0.1  
**Дата:** 03.06.2026  
**Статус:** Draft for Frontend / Backend Contract Tests

---

## 1. Назначение документа

Документ фиксирует API-контракт для MVP. Backend обязан реализовать OpenAPI schema, frontend обязан использовать типизированный API client.

---

## 2. API Principles

```text
REST JSON API
/api/v1 prefix
stable error format
auth required for user data
OpenAPI generated/exported
contract tests required
```

---

## 3. Common Error Schema

```json
{
  "error": {
    "code": "ERROR_CODE",
    "message": "Safe user/developer message",
    "details": {},
    "request_id": "uuid"
  }
}
```

Status codes:

```text
400 validation
401 unauthenticated
403 forbidden
404 not found
409 conflict
422 semantic validation
429 rate limit
500 server error
503 provider unavailable
```

## 4. Auth/User

### GET /api/v1/me

Auth: required

Response:

```json
{
  "id": "uuid",
  "email": "user@example.com",
  "display_name": "Andrey",
  "preferred_locale": "ru-RU",
  "role": "registered_user"
}
```

### PATCH /api/v1/me

Request:

```json
{
  "display_name": "Andrey",
  "preferred_locale": "en-US"
}
```

## 8. Runtime

### POST /api/v1/scenarios/{scenario_id}/start

Auth: required

Request:

```json
{
  "client_request_id": "uuid",
  "locale": "ru-RU"
}
```

Response:

```json
{
  "session_id": "uuid",
  "attempt_id": "uuid",
  "status": "active",
  "first_prompt": "Расскажите, как вы оформляете баг-репорт."
}
```

### POST /api/v1/sessions/{session_id}/messages

Request:

```json
{
  "content": "В баг-репорте я указываю title, steps..."

```

Response:

```json
{
  "message_id": "uuid",
  "saved": true,
  "attempt_id": "uuid"
```

## 11. Analytics

### POST /api/v1/analytics/events

Request:

```json
{
  "event_name": "trainer_viewed",
  "properties": {
    "trainer_slug": "qa-engineer-interview-trainer"
  }
}
```

Rule:

```text
Reject event if properties contain raw_answer, transcript, password, token.
```
