# 29. Beta Testing & User Feedback Plan
# Trainer Platform MVP Beta

**Версия:** 0.1  
**Дата:** 03.06.2026  
**Статус:** Draft for Product / QA / Analytics

---

## 1. Назначение документа

Документ описывает, как запускать beta testing после внутренней MVP-приемки.

---

## 2. Beta Goal

Проверить, что реальные пользователи могут:

```text
понять продукт
запустить QA Interview Trainer
пройти сценарий
получить понятную evaluation
повторить попытку
увидеть прогресс
дать feedback о полезности
```

---

## 3. Beta Cohorts

### Internal Alpha

```text
3–5 team/internal testers
goal: catch blocking bugs
```

### Closed Beta

```text
10–30 QA learners/candidates
goal: validate usefulness and flow
```

### Wider Beta

```text
50–150 users
goal: measure activation, completion, retention, cost
```

---

## 4. Beta Entry Criteria

```text
release readiness gates passed
no critical/high bugs
AI calibration accepted
privacy checks passed
analytics events working
feedback form ready
support channel ready
```

---

## 5. Beta Test Scenarios

Users must test:

```text
registration
language selection
trainer page
enrollment
bug report scenario
result page
retry
progress page
locale switch
evaluation feedback usefulness
```

---

## 6. Feedback Questions

Quantitative:

```text
Was it clear what to do? 1–5
Was feedback useful? 1–5
Did the score feel fair? 1–5
Would you retry? yes/no
Would you use it before interview? yes/no
```

Qualitative:

```text
Что было непонятно?
Какая оценка показалась неправильной?
Что добавить в feedback?
Какие QA-вопросы нужны ещё?
Где вы застряли?
```

---

## 7. Beta Success Criteria

```text
≥ 60% enrolled users start scenario
≥ 40% started users complete evaluation
≥ 70% users rate feedback usefulness 4/5 or 5/5
≤ 10% evaluation failure rate
0 privacy/security incidents
AI cost within budget
```

---

## 8. Beta Failure Criteria

```text
users do not understand product
scenario completion < 25%
feedback rated unfair by majority
critical errors pass
attempts lost
privacy issue
AI cost uncontrolled
```
