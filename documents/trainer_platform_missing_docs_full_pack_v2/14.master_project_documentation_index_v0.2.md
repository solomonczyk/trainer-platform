## 6. Forbidden Contradictions

Reject implementation if it violates:

```text
first MVP trainer is not QA Engineer Interview Trainer
one mega trainer instead of self-contained trainer products
free AI chat instead of scenario runtime
AI evaluation without rubric
score without evidence
PASS with critical error
progress stored only in localStorage
raw answers stored in analytics events
direct LLM calls outside AI Gateway
voice as mandatory MVP feature
medical/legal/finance/cybersecurity trainer without expert review
deployment without CI/health checks
implementation without NFR/SLO awareness
```
