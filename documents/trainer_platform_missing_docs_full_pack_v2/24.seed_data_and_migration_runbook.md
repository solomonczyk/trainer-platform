# 24. Seed Data & Migration Runbook
# Trainer Platform MVP Data Operations

**Версия:** 0.1  
**Дата:** 03.06.2026  
**Статус:** Draft for Backend / DevOps / QA

---

## 1. Назначение документа

Runbook описывает, как запускать миграции, загружать seed data, валидировать trainer package и откатывать изменения.

---

## 2. Migration Order

```text
1. users / auth tables
2. domains
3. trainer_products
4. trainer_versions
5. tracks/modules/scenarios
6. skills / skill_maps
7. rubrics / rubric_criteria
8. enrollments / sessions / attempts
9. evaluations / criteria results
10. progress / skill_scores
11. analytics_events
12. ai_requests
13. admin/audit tables if included
```

Command:

```bash
alembic upgrade head
```

---

## 3. Seed Order

```text
1. validate package files
2. seed domain: IT
3. seed trainer product: QA Engineer Interview Trainer
4. seed trainer version 1.0.0
5. seed skill map
6. seed rubrics
7. seed critical errors
8. seed scenarios
9. seed scenario steps
10. seed locale packs ru-RU/en-US
11. seed golden answers
12. run package validation after DB insert
```

---

## 4. Idempotent Seed Rules

```text
seed can run multiple times safely
use stable slugs/external IDs
update only seed-managed records
do not overwrite user attempts/evaluations/progress
do not delete production content automatically
```

---

## 5. Environment Rules

### local

```text
can reset DB
can reseed freely
can use mock AI provider
```

### staging

```text
seed approved MVP package
safe to reset only with team agreement
use synthetic users
```

### production

```text
seed only approved package
backup before seed/migration
no destructive reset
run validation before and after
```

---

## 6. Validation Before Seed

Required checks:

```text
all required files exist
JSON schema valid
rubric weights sum to 100
all locale keys present
all scenario rubric references valid
all skill references valid
critical errors defined
golden answer scenarios exist
```

---

## 7. Validation After Seed

Check DB:

```text
domain count >= 1
QA trainer exists
trainer version exists
5 scenarios exist
rubrics exist
locale rows exist
scenario list endpoint returns data
trainer page endpoint returns localized data
```

---

## 8. Rollback

### Schema rollback

```bash
alembic downgrade -1
```

Only if safe.

### Seed rollback local/staging

```text
delete seed-managed trainer package by trainer_product_id
preserve users unless reset explicitly approved
```

### Production rollback

```text
disable trainer visibility
restore backup if corruption
do not delete user attempts
```
