# Trainer Platform UI Components

**Версия:** 0.1  
**Дата:** 03.06.2026  
**Статус:** Draft for UX / Frontend

---

## 1. Назначение документа

Документ фиксирует UI-компоненты, состояния и визуальные паттерны для MVP.

---

## 2. Design Principles

```text
clear
calm
professional
non-gamified unless trainer requires
feedback-focused
mobile-friendly
accessible
```

## 4. Score Components

### ScoreBadge

States:

```text
excellent 90-100
good 75-89
acceptable 60-74
weak 40-59
failed 0-39
```

Must show:

```text
numeric score
text label
not only color
```

---

## 5. Feedback Components

### EvidenceBlock

Must show:

```text
criterion
evidence from user answer
comment
improvement
```

### CriticalErrorAlert

Tone:

```text
specific
serious
non-shaming
actionable
```

Example:

```text
В ответе есть критичная ошибка: вы сказали, что steps to reproduce не нужны.
Это блокирует PASS, потому что без шагов баг часто невозможно воспроизвести.
```

## 6. Scenario Runner Layout

Required areas:

```text
trainer/scenario header

```

## 7. Form States

Every form must support:

```text
default
focused
valid
invalid
submitting
disabled
success
error
```

---

## 8. Loading/Error/Empty States

Required:

```text
loading domains
empty trainer list
scenario unavailable
evaluation pending
evaluation failed
progress empty
network error
unauthorized
```

---

## 9. Responsive Breakpoints

```text
mobile: < 640
tablet: 640–1024
desktop: > 1024
```

Mobile rules:

```text
scenario runner single column
sticky submit allowed
result sections stacked
rubric breakdown collapsible
```
