# 31. AI Cost Budget & Unit Economics Guardrail
# Trainer Platform AI Cost Control

**Версия:** 0.1  
**Дата:** 03.06.2026  
**Статус:** Draft for Product / DevOps / AI / Analytics

---

## 1. Назначение документа

Документ фиксирует бюджетные ограничения AI-вызовов и правила предотвращения cost spike.

---

## 2. Cost Principles

```text
AI cost is product metric
cost per evaluation must be tracked
model choice must be configurable
retry must be bounded
expensive features behind flags
```

---

## 3. MVP Cost Metrics

```text
cost_per_evaluation
cost_per_completed_scenario
cost_per_active_user
daily_ai_cost_total
evaluation_cost_by_scenario
evaluation_cost_by_model
failed_ai_cost
```

---

## 4. Budget Guardrails

Initial MVP targets:

```json
{
  "max_cost_per_evaluation_usd": 0.05,
  "max_daily_ai_cost_staging_usd": 5,
  "max_daily_ai_cost_beta_usd": 25,
  "max_retries_per_evaluation": 1,
  "max_evaluations_per_user_per_day_free": 10
}
```

Values are adjustable after real pricing validation.

---

## 5. Model Tier Policy

```text
standard model for normal evaluation
cheaper fallback for retry if quality acceptable
high-quality model only for calibration/review if needed
no expensive model by default in public beta without approval
```

---

## 6. Cost Alerts

Alert if:

```text
daily cost > budget
cost per evaluation > threshold
failed AI requests cost > 20% of total
single user exceeds limit
provider error spike causes retries
```

---

## 7. Rate Limits

```text
per user per minute
per user per day
per IP for guests
per scenario evaluation retry
global daily AI budget
```
