## 5. Retry Policy

Allowed retry:

```text
provider timeout
rate limit after backoff
invalid JSON once if retry budget remains
```

Forbidden blind retry:

```text
retry without logging reason
retry after safety violation
retry after cost limit exceeded
unbounded retry loop
```

---

## 6. Fallback Policy

Fallback allowed only if:

```text
primary provider unavailable
fallback model supports JSON output
fallback passes same schema validation
fallback cost within budget
fallback event logged
```

---

## 7. Prompt Versioning

Rules:

```text
prompt changes require new version
evaluation stores prompt_template_id and prompt_version
calibration tests required before activation
rollback keeps old prompt available
```

Statuses:

```text
draft
test
active
deprecated
blocked
```
