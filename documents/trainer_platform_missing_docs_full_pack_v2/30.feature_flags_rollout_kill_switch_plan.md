## 3. Kill Switches

### Disable AI Evaluation

Use if:

```text
AI provider failing
invalid evaluations
cost spike
unsafe feedback
```

Behavior:

```text
attempt saved
evaluation status = temporarily_unavailable
user sees safe message
no data loss
```

### Disable Trainer Visibility

Use if:

```text
trainer package invalid
content issue
critical rubric bug
```

Behavior:

```text
existing attempts remain accessible
new starts blocked
admin sees reason
```

### Disable Locale

Use if:

```text
locale incomplete
bad translation
feedback language mismatch
```
