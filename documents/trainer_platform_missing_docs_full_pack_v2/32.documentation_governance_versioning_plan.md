## 1. Назначение документа

Документ фиксирует, как управлять документацией, чтобы source of truth не расползался и агенты не работали по устаревшим требованиям.


## 5. Change Control

Changes requiring docs update:

```text
first trainer changes
MVP scope changes
API contract changes
DB schema changes
evaluation contract changes
AI provider/model policy changes
analytics event changes
privacy/data collection changes
release gate changes
```

---

## 6. Conflict Resolution

If documents conflict:

```text
1. identify affected source-of-truth area
2. update owning document first
3. update dependent documents
4. record changelog
5. do not implement until conflict resolved
```

Example:

```text
First MVP trainer must be QA Engineer Interview Trainer.
Prompt Engineer Trainer is later/alternative, not MVP baseline.
```
