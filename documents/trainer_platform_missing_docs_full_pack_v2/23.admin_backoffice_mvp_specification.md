# 23. Admin / Backoffice MVP Specification
# Trainer Platform Admin MVP-lite

**Версия:** 0.1  
**Дата:** 03.06.2026  
**Статус:** Draft for Admin / Backend / Frontend

---

## 1. Назначение документа

MVP не включает полноценную Authoring Studio, но требует минимальный admin/backoffice слой для проверки seed data, trainer package, AI failures и system health.

---

## 2. MVP Admin Scope

Included:

```text
admin login/role access
seed status view
trainer package validation status
published trainer overview
scenario list/status
AI evaluation failures overview
analytics sanity view
system health page
```

Excluded:

```text
visual scenario editor
rubric editor
publishing workflow UI
B2B admin
billing admin
user impersonation
```

---

## 3. Admin Routes

```text
/admin
/admin/seed-status
/admin/trainers
/admin/trainers/[trainerSlug]
/admin/evaluations/failures
/admin/analytics/sanity
/admin/system-health
```

---

## 4. Seed Status View

Show:

```text
domain IT exists
QA Engineer Interview Trainer exists
trainer version 1.0.0 exists
5 MVP scenarios seeded
rubrics seeded
skill map seeded
ru-RU locale seeded
en-US locale seeded
golden answer set seeded
```

Status:

```text
valid
missing
invalid
outdated
```

---

## 5. Trainer Package Validation View

Show validation checks:

```text
rubric weights sum to 100
scenario references existing rubric
scenario references existing skills
locale keys complete
critical errors defined
golden answers linked
```

---

## 6. AI Evaluation Failures View

Show:

```text
attempt_id
scenario_id
error_type
provider/model
prompt_template_id
prompt_version
latency
retryable
created_at
```

Do not show full raw answer by default.

---

## 7. Analytics Sanity View

Show counts:

```text
trainer_viewed
trainer_enrolled
scenario_started
answer_submitted
evaluation_received
scenario_completed
progress_viewed
ai_request_completed
ai_request_failed
```

---

## 8. System Health View

Show:

```text
backend health
database connection
migration version
AI Gateway configured
current AI provider
current evaluator model
analytics enabled
last successful evaluation
```

---

## 9. Forbidden Admin Actions in MVP

```text
edit published scenario directly
edit rubric directly
delete user data without deletion workflow
view all raw answers casually
publish new high-risk trainer
change AI prompt from UI
```

---

## 10. Admin Tests

```text
non-admin cannot access admin routes
admin can view seed status
seed status detects missing locale
package validation detects bad rubric weights
AI failure view hides raw answer
system health shows database status
```
