# 20. Trainer Package Schema Specification
# Canonical Trainer Product Package

**Версия:** 0.1  
**Дата:** 03.06.2026  
**Статус:** Draft for Backend / Content / QA  
**First package:** QA Engineer Interview Trainer v1.0.0

---

## 1. Назначение документа

Документ фиксирует канонический формат trainer package. Он нужен, чтобы каждый тренажер был переносимым, валидируемым и версионируемым.

---

## 2. Package Structure

```text
qa_engineer_interview_trainer/
├── trainer.json
├── trainer_version.json
├── skill_map.json
├── rubric_pack.json
├── critical_errors.json
├── scenarios/
│   ├── qa_self_presentation_v1.json
│   ├── qa_test_case_vs_checklist_v1.json
│   ├── qa_bug_report_structure_v1.json
│   ├── qa_regression_vs_retest_v1.json
│   └── qa_login_form_testing_v1.json
├── locales/
│   ├── ru-RU.json
│   └── en-US.json
├── golden_answers/
│   └── qa_golden_set_v1.json
└── package_tests/
    └── validation_cases.json
```

## 10. Validation Rules

Package validation fails if:

```text
missing trainer.json
missing supported locale
scenario references unknown rubric
scenario references unknown skill
rubric weights do not sum to 100
critical error referenced but not defined
locale key missing for published scenario
golden answer references unknown scenario
```
