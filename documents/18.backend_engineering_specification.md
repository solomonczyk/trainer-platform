## 1. Goal

Реализовать backend как FastAPI modular monolith, который поддерживает:

```text
auth/profile
domain catalog
trainer registry
trainer package seed
scenario runtime
attempt persistence
AI Gateway
rubric evaluation
progress engine
analytics
admin seed/status
```

## 3. Layer Rules

```text
router → service → repository → database
router → service → ai_gateway only through service
```

Routers:

- parse request;
- check permissions dependency;
- call service;
- return response schema.

Services:

- own business rules;
- own transactions;
- call repositories;
- call AI Gateway.

Repositories:

- DB queries only;
- no business decisions.

## 4. Required Backend Modules

### Auth Module

Responsibilities:

```text
register/login/current user
role resolution
protected route dependencies
```

MVP roles:

```text
guest
registered_user
admin
```

### Trainer Registry Module

Responsibilities:

```text
domains
trainer_products
trainer_versions
trainer localizations
published status
```

### Scenario Runtime Module

Responsibilities:

```text
start scenario
create session
create attempt
store messages
complete attempt
prevent duplicate active conflicts
```

### Evaluation Runtime Module

Responsibilities:

```text
load attempt
load rubric
call AI Gateway
validate evaluation
store evaluation
store criterion results
handle AI failure safely
```

### Progress Module

Responsibilities:

```text
create progress on enrollment
update skill scores after evaluation
calculate readiness
recommend next scenario
```

### Analytics Module

Responsibilities:

```text
record events
block raw answer text in properties
attach trainer/scenario context
```

## 5. Transaction Boundaries

Critical transaction examples:

### Start scenario

```text
create simulation_session
create attempt
record scenario_started event
commit together
```

### Submit answer

```text
validate active session
store simulation_message
record answer_submitted event without raw answer
commit before any AI call
```

### Complete and evaluate

```text
mark attempt completed
commit
call AI Gateway outside DB lock
store evaluation in separate transaction
update progress
record evaluation_received
```

## 7. Idempotency Rules

Required idempotency:

```text
trainer enrollment
scenario start with same client request id
evaluation retry
analytics event optional dedupe
seed scripts
```

Enrollment rule:

```text
same user + trainer_version = one active enrollment
```

---

## 8. AI Gateway Integration

Forbidden:

```text
from openai import ... inside evaluation service
```

Required:

```python
ai_gateway.evaluate_attempt(request: EvaluationGatewayRequest) -> EvaluationGatewayResult
```

Gateway must return:

```text
validated_output or controlled failure
provider metadata
cost metadata
validation metadata
```
