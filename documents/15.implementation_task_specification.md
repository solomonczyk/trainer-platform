# 15. Implementation Task Specification
# Техническое задание на первый полный implementation layer

**Версия:** 0.1  
**Дата:** 03.06.2026  
**Статус:** Draft for Engineering Agent / Tech Lead Review  
**Назначение:** превратить всю документацию в одно цельное задание на реализацию MVP vertical slice.

---

## 1. Goal

Создать первый рабочий vertical slice платформы самодостаточных профессиональных тренажеров:

```text
Platform Core + IT Domain + QA Engineer Interview Trainer
```

Система должна доказать, что можно:

```text
создать trainer product
опубликовать trainer version
запустить сценарий
сохранить attempt
получить AI evaluation по рубрике
показать result
обновить progress
записать analytics
развернуть через CI/CD
```

## 4. Required User Journey

The following full journey must work:

```text
User registers
→ selects ru-RU or en-US
→ opens Domains
→ opens IT
→ opens QA Engineer Interview Trainer
→ enrolls
→ opens scenario list
→ starts Bug Report scenario
→ submits answer
→ attempt is saved
→ AI evaluation is generated
→ result page shows score/evidence/feedback/next action
→ progress page updates
→ analytics events are recorded
```
